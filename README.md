mend is one patch tool for every AI edit format: it applies unified diffs, SEARCH/REPLACE blocks, V4A patches, and JSON edits to a tree of text files, matching lines at three tiers (exact, trailing-whitespace, indentation), and writes every change or none at all.

## Run it

```sh
node main.ts [options] [PATCH]
```
